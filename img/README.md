# Image du hero

Les fichiers `hero-botanique-*` sont des déclinaisons locales et optimisées de
la photographie utilisée historiquement par le projet :

- source originale : https://images.unsplash.com/photo-1545241047-6083a3684587
- licence : https://unsplash.com/license
- formats applicatifs : AVIF et WebP, largeurs 640, 960 et 1440 px ;
- usage : hero responsive et image de repli du catalogue.

La photographie est distribuée selon la licence Unsplash applicable à la
source. Le fichier `hero-social-1200.jpg` est réservé aux aperçus sociaux et
n'est pas chargé par l'interface.
